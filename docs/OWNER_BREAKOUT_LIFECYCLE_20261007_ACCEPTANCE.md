# Пробой → удержание → добор: правила владельца от 7 октября 2026

## Область применения

Общая модельная логика для CNYRUBF, BTC, ETH, NQ, MOEX, GOLD и BRENT. Используются существующие ограничения каждого портфеля; Валютный остаётся только CNYRUBF. Реальные заявки и изменение брокерских разрешений не входят в это исправление.

Источник правила в рабочем каталоге обучения: `veritas_user_teaching.breakout_policy_snapshot()`, идентификатор `USER_INTRABAR_STRUCTURE_2026_10_07`. Исходная запись не переписывается. Она содержит пример владельца, причинные ограничения и ссылку на исходные свечи. Наличие функции записи не является подтверждением успешного чтения записи из рабочей базы.

## Обязательный алгоритм

1. Свежая котировка закреплённого источника пересекает уже известный локальный максимум: возникает LONG. Для SHORT всё зеркально. Закрытия пробойной свечи ждать не требуется; подтверждение самого исторического уровня использует только уже доступные свечи.
2. Нет позиции — проверка допуска и открытие модельной позиции. Позиция в ту же сторону — удержание; новый самостоятельный пробой может дать один добор. Повторный опрос того же события не даёт повторной покупки.
3. Для нового структурного движения стоп за последним противоположным подтверждённым экстремумом выбранного структурного таймфрейма. Этот минимум/максимум может сформироваться ПОСЛЕ вершины/дна, которое затем пробивается. Его доступность проверяется на время котировки, не на текущую дату просмотра.
4. Уже открытое движение сохраняет защищённый стоп. Добор не разрешает отодвинуть его или заменить его микроскопическим стопом младшей свечи. Новый подтверждённый структурный экстремум может только уменьшить риск. Время сигнала, таймфрейм исполнения, таймфрейм защищённой структуры и ATR записываются отдельно.
5. Перед добором рассчитывается риск ВСЕЙ позиции по действующему стопу, включая предыдущий объём, новый объём, комиссии, проскальзывание и фондирование. Ограничения плеча и просадки сохраняются. Недостаток свободного риска означает удержание без добора, а не автоматический выход из правильной позиции.
6. Цели — предыдущие подтверждённые более крупные зоны проторговки. Частичная фиксация на первой, остаток на второй. Дальняя цель не придумывается для улучшения отношения дохода к риску. Пробой следующей исторической зоны — новое событие с новыми ранее известными целями; достигнутую цель старой сделки нельзя молча отодвигать.
7. Истечение времени для нового входа не отменяет само по себе тезис уже открытой позиции. Источник, действующий стоп, подтверждённое изменение структуры и ограничения портфеля остаются обязательными.

## Пример владельца — не доказательство исторического исполнения

| Момент, Москва | Событие | Защита и цели |
|---|---|---|
| 07:00 | Пробой 12,727: LONG / подтверждение удержания | Стоп ниже 12,693 с буфером волатильности структурного таймфрейма |
| Около 10:14 | Пробой указанного уровня 12,750: открытие / добор | Проверить общий риск; защищённый минимум 12,693; зоны целей 12,805 и 12,840 |
| Новый пробой 12,840 | Продолжение LONG | Стоп по действующей защищённой структуре, новые ранее наблюдавшиеся старшие зоны |

Числа из примера не зашиты в рабочий алгоритм. В существующем файле `tests/fixtures/cny_structural_20261007.json` минутные свечи уточняют последовательность: повторное пересечение 12,750 относится к 10:13, а свеча 10:14 пересекает локальные максимумы 12,756/12,760. Минутные OHLC не позволяют доказать точную внутриминутную цену или исполнение в указанную секунду. Поэтому сохраняются отдельно формулировка владельца и доступные наблюдения.

## Что уже было в основной ветке при проверке

- Пробой по свежей котировке без ожидания закрытия пробойной свечи; отдельный модельный цикл с целевым интервалом 5 секунд.
- Сохранение идентификатора источника Т-Банка при повторной проверке плана.
- Структурные цели и расчёт взвешенного результата частичных выходов; фиксированный порог R/R 1,15 не является запретом для валидированного модельного структурного плана. Условия реального исполнения не ослабляются.
- Сохранение защищённого стопа, повторная проверка суммарного риска, отсутствие повторного добора по одному событию.
- Запись исходного правила в рабочем каталоге обучения.

## Исправление этой проверки

`veritas_structural_breakout._leg_for` выбирал старый противоположный экстремум перед исходной вершиной, даже если после вершины и до пробоя уже был подтверждён новый локальный минимум. Удалён этот ошибочный приоритет. Новый вход использует последний известный противоположный экстремум; ветка управления уже защищённой позицией не изменена.

Добавлены 8 методов проверок в `test_veritas_last_confirmed_swing.py`, включая оба направления для семи инструментов, недоступные будущие подтверждения, запрет микростопа и расширения стопа, разрешённое структурное подтягивание и неизменность входных данных. Они включены в обязательную группу через `test_veritas_structural_breakout.py`.

## Граница подтверждения

Тесты подтверждают правила и вычисления, но не прибыльность стратегии и не фактическое исполнение пропущенных исторических сделок. Целевые пять секунд не являются гарантированной измеренной задержкой: доступность котировки и блокировки общей книги требуют отдельного контроля в работающем сервисе. Исправление задержек и частичных отображений не заменяется этим изменением стопа.
