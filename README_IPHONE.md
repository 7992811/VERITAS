# VERITAS MAX → @axednewz

Версия 1 для безопасного запуска через Render с iPhone.

Что делает:
1. GPT-5.6 Terra каждые 10 минут ищет значимое новое событие.
2. GPT-5.6 Sol независимо перепроверяет его через веб-поиск.
3. Если доказательности недостаточно — пост блокируется.
4. Готовый текст приходит администратору Telegram.
5. Есть кнопки «Опубликовать» и «Отклонить».
6. Только после подтверждения текст уходит в @axednewz.

Никогда не добавляйте в GitHub реальные:
- TELEGRAM_BOT_TOKEN
- OPENAI_API_KEY

Их нужно вводить только в Render → Environment.

Загрузите в корень GitHub-репозитория все 7 файлов из архива.

После запуска, если ADMIN_USER_ID пустой:
- откройте личный чат с ботом;
- нажмите Start или отправьте /start;
- бот покажет ваш Telegram user ID;
- добавьте это число в Render как ADMIN_USER_ID;
- перезапустите worker.

Команды:
- /status
- /scan
- /pause
- /resume

Ограничение версии 1:
источник рыночной информации — веб-поиск OpenAI, а не прямая биржевая лента.
Поэтому первый режим намеренно только с ручным подтверждением.
